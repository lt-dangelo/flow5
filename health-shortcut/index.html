Apple Health export — iPhone pilot

This is an experimental Shortcut integration, not direct HealthKit access. Pick5Go only sends workout start/end time and elapsed duration to your own iPhone Shortcut. Nothing is sent to a Pick5Go server.

1. Create a Shortcut on your iPhone

  1. Open Apple's Shortcuts app. Create a shortcut named exactly Pick5Go Health.
  2. Add Get Dictionary from Input using Shortcut Input (the text supplied by Pick5Go).
  3. Use Get Dictionary Value for the key durationMinutes. Keep the numeric output for the workout duration.
  4. Use Get Dictionary Value again for start. Convert that ISO date string with Get Dates from Input, and use the resulting date as the workout start time.
  5. Add Log Workout. Choose Functional Strength Training if your version of Shortcuts offers it, insert the start date and duration (minutes) variables, and leave calories/distance unspecified when possible.
  6. Optionally add an Ask for Confirmation action before logging to prevent accidental duplicate workouts.

Shortcuts field names and available workout categories vary by iOS version. If you cannot bind the start time or duration to the Log Workout action, stop at this step rather than logging inaccurate data.

2. Test with Pick5Go

  1. Complete a workout in the Pick5Go preview on your iPhone.
  2. On the completion screen, expand Export to Apple Health (Shortcut test).
  3. Tap the button to launch the shortcut and review or approve its Health permissions.
  4. Verify the resulting workout in Apple Health or Fitness. Delete it if its start time, duration or category is incorrect.

Data passed to Shortcuts

{
  "version": 1,
  "source": "Pick5Go",
  "type": "Functional Strength Training",
  "start": "2026-10-27T12:00:00.000Z",
  "end": "2026-10-27T12:15:00.000Z",
  "durationMinutes": 15
}

Limitations: Duration measures elapsed time from starting to completing the workout and includes pauses. It does not verify that you performed the movements. No energy expenditure, distance, heart rate or repetition counts are measured or estimated. The shortcut operates only on your own device with the permissions you give it. Avoid importing the same session twice.

References: Apple Shortcuts URL integration and Apple Fitness manual workout logging.
